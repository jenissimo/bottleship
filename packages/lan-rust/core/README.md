# BottleShip LAN core

Pure protocol-v1 state machine for the Rust server. The caller serializes commands and performs transport/native effects. This crate does not spawn tasks or perform DNS/socket I/O.

`Core::join(connection, auth, now_ms)` validates room identity and returns effects. Delay the new participant's ready event until Socket.IO namespace activation. `Core::apply(Command)` handles input, disconnect, output rejection, native completion, configured DNS completion and expiry.

`Arg::Binary(Bytes)` preserves shared admitted buffers; `Arg::Json(Value)` preserves an explicit null. Missing generation is legacy input; explicit null/zero is invalid. `ServerEvent::args()` omits absent generation rather than serializing null.

`Effect::Emit` includes recipient, originating participant, reliability and logical retained bytes. The transport must bound its actual encoded Engine.IO/sink buffers too. Reliable rejection disconnects both affected participants. Native I/O consumes ordered `GatewayInput` and returns fenced `GatewayEvent`.

Only configured routes are resolved. Build `Routes` from `GatewayConfig`, pin startup numeric/DNS snapshots with `Routes::pin`, then construct `Core`. A guest resolve emits `Effect::ResolveRoutes { connection, operation, request_id, route_ids }`; the host resolves only those configured host fields and replies with `Command::RoutesResolved { connection, operation, resolutions }`. Pending queries are capped at16. `Effect::CancelResolve` cancels the operation; canceled/retired completions cannot answer a reused request ID. An unconfigured name never creates a DNS effect.

Native target descriptors include numeric host scope, route ID and canonical policy identity. Guest IPv6 scope IDs are separately advertised. Binding generations and native lease IDs prevent late close/error/completion from reviving a retired owner. Actual TCP/RAW/UDP stream mechanics belong to the gateway/native crates. Host-listen is a separate future capability.

Run pure tests:
```text
cargo test --manifest-path packages/lan-rust/core/Cargo.toml --jobs 1
```

The differential frame fixture is generated by executing the maintained TypeScript codec:
```text
bun packages/lan-rust/core/tests/js/generate-vectors.ts
```
`tests/js/black-box.ts` exports real Socket.IO cases reusable against a caller-owned TS or Rust endpoint. Tests do not create an external service automatically. Current unit tests cover configured DNS refresh/cancel/caps, source rewriting, isolated rooms, replacement/late callbacks, output refusal, generation tombstones and native lease cancellation. This does not establish full server/native parity.
