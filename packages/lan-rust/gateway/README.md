# BottleShip native gateway actors

This crate executes authenticated Core gateway effects. It does not accept arbitrary destinations: the root dispatcher obtains a configured numeric Target from Core Routes, passes the authenticated participant node to Gateway::spawn_with_node, and shares one DestinationPolicy across all rooms. Protocol v1 remains the TypeScript reference wire format.

Each participant actor has bounded command and event queues. Native receive ownership stays in GatewayOutput until the dispatcher has applied Core effects and admitted their transport output. Close interrupts pending startup independently of command capacity; native policy and identifier leases are released after physical retirement.

Ordinary UDP uses one unconnected OS socket per binding/family and exact peer tuples. The default Socket2/Tokio backend supports numeric IPv4, IPv6 and mapped destinations. The opt-in existing bound-UDP helper preserves measured original ICMP error tuples. An unattributed default-backend error is counted separately and is never assigned to a current peer or broadcast to peers. Successful UDP sends are never retried.

TCP uses the canonical BST1 framing, two independent 262144-byte credit windows and ordered DATA/OOB/FIN. Urgent data and OOBINLINE require the optional native helper. EOF retains uncredited data until final DATA/FIN admission, then releases a physically closed flow.

RAW uses authenticated guest addresses, global echo identifier NAT, UDP source-port reservations and the explicit destination-exclusive generic backend. The measured Windows ICMP4/6 packet tests used two participants with the same original identifier and verified isolated replies, packet addresses and checksums. The RAW UDP4/6 packet tests returned native permission error 10013; no successful packet path is claimed for those arms. RAW6 wildcard/unknown receive protocol classification is rejected explicitly. Fragmented UDP and unknown IPv6 extension chains are not translated. Generic raw TCP/unknown protocols retain destination exclusivity; this does not provide full raw coexistence. OS permissions and native errors are preserved. Lifecycle and IPC tests alone do not establish packet parity.

Run core tests with cargo test --manifest-path ../core/Cargo.toml. Gateway tests require an explicitly measured BOTTLESHIP_RUST_UDP_HELPER path. Build the test-only startup_stall example and set BOTTLESHIP_RUST_STARTUP_FIXTURE to it before gateway tests. These tests never build or modify the production C helper. The adversarial example withholds READY or ACK, owns a real ordinary loopback port and has a finite watchdog; it is not a production backend.

The opt-in udpHostListenV1 capability binds an actual IPv4 Host listener from gateway.udpListeners. Each definition requires id, bindHost, advertisedHost, port and allowedHosts. The addresses are numeric IPv4; bindHost may be 0.0.0.0, whereas advertisedHost and the 1..32 distinct allowedHosts must be unicast. port:0 selects an actual OS port. maxOwners defaults to 1 (1..64), maxPeers to 64 (1..128) and idleTimeoutMs to 60000 (1..3600000). There are at most 32 distinct listener IDs.

READY follows actual bind, contains the advertised address and actual bound port, and precedes forwarded input. The source-IP ACL admits incoming traffic; outgoing replies additionally require a nonexpired exact IP/port tuple learned from real received traffic. Lookup does not refresh or manufacture a peer lease, and send checks its epoch again. No dummy packet or outgoing route is required for the first permitted incoming datagram. A global listener-owner slot and destination-policy leases stay held until physical retirement, including cancelled startup and queue-independent abort.

Host errors and data carry the exact native lease ID as well as binding generation. udpHostClosed carries both the original request ID and public lease ID. The emulator must opt in with network.directPlay8:{provider:"native",hostListener:"configured-id"}. Without that policy the virtual room provider remains separate; unavailable capabilities and unsupported native modes do not receive fabricated success. The current measured native Host scope is DirectPlay8 Peer Host plus one remote participant (maxPlayers=2), not arbitrary mesh or complete DirectPlay parity.

Configured route DNS and its global OS-work limit belong to the root dispatcher. A cancelled or timed-out lookup cannot publish into a retired request, but a blocking OS call retains its resolver permit until it returns. Gateway actors receive resolved, policy-authorized numeric targets; they do not resolve arbitrary client names.

Source behavior is ported from the Apache-2.0 TypeScript BottleShip LAN package, including raw-gateway.ts, raw-generic.ts, raw-udp.ts and icmp-nat.ts. See the core package NOTICE and LICENSE. Host listeners are a separate capability and do not reinterpret protocol-v1 exact peer permissions.
