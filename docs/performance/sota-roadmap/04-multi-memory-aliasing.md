# 04. Multi-memory: CPU-state в отдельной wasm-памяти

## Видение

v86 эмитит WASM руками без IR, оптимизацию делает TurboFan. У него одна alias-класс на всю
линейную память: любой guest-store убивает все ранее загруженные значения CPU-состояния,
которое живёт в той же памяти (lazy flags `last_op1/last_result`, x87-стек, `tlb_data`,
segment bases). Регистры уже в locals, их это не касается; всё остальное перезагружается
после каждого store.

Multi-memory (Chrome 120+) позволяет положить CPU-state во вторую память. TurboFan
различает alias-классы по индексу памяти, и guest-store перестаёт инвалидировать загрузки
состояния. Это единственный способ дать host-оптимизатору alias-информацию без своего IR.

Уверенность средняя: выигрыш зависит от того, сколько повторных загрузок состояния
TurboFan сейчас генерирует. Это однодневная проба с чётким OFF-arm, не обязательство.

## Как снять

1. Прямая проверка без переписывания: выгрузить wasm одного горячего модуля (например
   `cry3dengine+0x73000`), прогнать через standalone d8 с `--print-wasm-code` и посчитать
   loads из CPU-state, следующие за guest-store. Если их мало, пункт закрывается без
   реализации.
2. Микро-проба в Rust: перенести только lazy-flags поля во вторую память (самые частые
   загрузки), собрать v86, измерить CPU-арм демки.
3. OFF/ON по общему протоколу; отдельно время компиляции модулей, потому что вторая память
   меняет форму импортов.

## Синтетические тесты

Correctness:

- Существующие `fpu-absolute` и AOT-oracle self-test покрывают семантику; добавить
  сравнение снапшота полного CPU-state (`saveCpuContext`) после фиксированной трассы.
- `validate-hypercall-abi` обязан знать о второй памяти; TS-сторона читает CPU-state
  через `cpu[...]` массивы, и их backing buffer меняется.

Perf fixture: CPU-арм `demo_fc_rebench` плюс микродемка `demo_flags_dense` (ALU-плотный
код с частыми store-ами между арифметикой), где эффект должен быть максимальным.

## Критерий успеха

Положительная медиана на `demo_flags_dense` выше noise floor. Если там выигрыша нет, на
Far Cry его тем более не будет, и пункт закрывается записью в negative-results.
