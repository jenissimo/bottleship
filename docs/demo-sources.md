# Источники демо для production-библиотеки

Проверка источников: **2026-10-05**. Инвентарь: все **50 WGB** в `G:\WGB\running`.
После дополнительного разрешения выполнена автономная загрузка дистрибутивов **19 игр**
в `G:\WGB\demo-downloads\2026-10-05`. Собраны **11 новых WGB**, семь проверенных демо
скопированы в production-библиотеку и включены в каталог. Результаты указаны ниже;
исходный инвентарь сохраняет остальные кандидаты для дальнейшего поиска.
Полная игра, ремейк, фанатский проект и данные без исходного Win32 EXE не заменяют демо.

**Готово** означает существующий WGB в `G:\WGB\prod-library`; **очередь** — найден
источник демо соответствующей игры; **условно** — другая редакция, trial, историческое
свидетельство или неподтверждённый состав. **Не найдено** не означает, что демо никогда
не существовало. Условия распространения исходного демо проверяются перед публикацией WGB.

## Уже опубликованные демо вне этого инвентаря

`airfix-dogfighter-demo.wgb`, `overboard-demo.wgb`, `thps2-demo.wgb`, `ut_demo.wgb`
уже находятся в production-библиотеке. Для Airfix Dogfighter и Overboard проверены только
демо, полные версии не тестировались. `tiberian-sun.wgb` — существующая freeware-поставка,
а не демо. Всего после добавления Warcraft в `prod-library` **14 WGB**.

Из текущих production-демо кнопка импорта купленной GOG-версии добавлена для **Re-Volt**
и **Heroes III**. По мере перепаковки очереди новые карточки должны получать ссылку на
конкретный GOG-продукт только после проверки подходящей Win32-редакции.

Warcraft III Demo: **111 182 186 байт**, SHA-256
`7B7CB417A7726407577B08CD6570A22CE50BCB1E0D4E921192B78BE2C130E847`.
Исходник и production-копия совпадают. Публичная карточка появится после выкладки сайта
с обновлённым `public/games-catalog.json`; загрузка одного WGB не выкладывает сайт.

## Автономная загрузка и проверка 2026-10-05

19 файлов Internet Archive получены для 17 игр (две редакции Hitman и BIN + CUE Gothic).
Размеры и MD5 сверены с metadata архивного каталога; SHA-256 записан после загрузки.
Дополнительно получены Quake II 3.14 с зеркала id Software и Worldwide Demo Red Faction
с FactionFiles. Исходники не запускались как Windows-программы; распаковка использует
собственные format readers. Неподдержанные контейнеры сохранены для диагностики.
Квитанции с хешами находятся рядом с дистрибутивами в `acquisition.json`, хеши новых
production WGB — в `production-bundles.json`. У FactionFiles не найден исходный checksum;
локальный SHA-256 фиксирует полученный файл, но не является независимым подтверждением.
